# inventory-fixtures/msgs

`crates/vkstorm-inventory/tests/fixtures/msgs/` (the inventory UDP message
handlers, survey 4 set 8) is recorded by the same viewer executable as the
cache fixtures, `INTEGRATION_TEST_llinventorymodel_parity` (recorder R2), and
regenerated with them by `tools/inventory-fixtures/cache/regenerate.py`, which
writes both directories.
